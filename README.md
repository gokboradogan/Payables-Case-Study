# Payables-Case-Study
Independent audit case on trade payables, cutoff testing, supplier reconciliation, and unrecorded liabilities.
The analysis covers supplier balance differences, year-end cutoff, unmatched GRNs, debit balances, and potential unrecorded liabilities.

## Audit Areas
- Completeness and cutoff testing
- Supplier statement reconciliation
- Search for unrecorded liabilities
- Debit balance classification
- Risk assessment and proposed audit procedures

## Files
- `01-Payables-AuditCase.pdf` — Source dataset and audit prompts
- `02-Payables-Risk-Assessment.pdf` — My audit findings, procedures, evidence requirements, and proposed adjustments

*Prepared as an independent learning project for audit practice.*
